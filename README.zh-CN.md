\# MetaMask Desktop | 小狐狸钱包桌面端应用程序



\[English](README.md) | \[日本語](README.ja.md)



\*\*MetaMask Desktop\*\* 是一款专为 Windows、macOS 和 Linux 用户打造的跨平台桌面钱包应用程序 \[MetaMask-AI/metamask-desktop](https://github.com/MetaMask-AI/metamask-desktop)。本项目提供了一种独立于浏览器扩展程序（小狐狸插件）的桌面优先体验，具备更高的稳定性、更强的性能以及系统级集成能力，用于管理加密货币钱包、与 Web3 应用程序交互并访问 DeFi 和 NFT 等去中心化生态系统。



\## 核心特性



\- \*\*无需浏览器插件\*\*：摆脱臃肿的浏览器标签页，完全独立运行。

\- \*\*本地加密存储\*\*：私钥经过加密后安全地保存在您的本地设备中，绝不上传服务器。

\- \*\*多账户与自定义 RPC\*\*：支持多钱包账户管理、助记词导入/导出，以及轻松切换以太坊、Polygon、BSC 等自定义 RPC 网络。

\- \*\*硬件钱包支持\*\*：集成主流硬件钱包，保障冷存储资产安全。

\- \*\*内置 Web3 Provider\*\*：无缝连接各类去中心化应用（DApps），便捷交易 ERC-20 代币与 ERC-721/ERC-1155 NFT。



\## 安装指南



\### Windows

1\. 从 \[Releases 页面](https://github.com/MetaMask-AI/metamask-desktop/releases) 下载最新的 `.exe` 安装包。

2\. 运行安装程序并按照提示完成设置。



\### macOS

1\. 从 \[Releases 页面](https://github.com/MetaMask-AI/metamask-desktop/releases) 下载最新的 `.dmg` 镜像文件。

2\. 打开该文件并将应用程序拖动到 \*\*Applications\*\*（应用程序）文件夹中。



\### Linux

1\. 从 \[Releases 页面](https://github.com/MetaMask-AI/metamask-desktop/releases) 下载 `.AppImage` 文件。

2\. 打开终端并运行以下命令：

&#x20;  ```bash

&#x20;  chmod +x MetaMask-Desktop-1.6.0.AppImage

&#x20;  ./MetaMask-Desktop-1.6.0.AppImage

&#x20;  ```
