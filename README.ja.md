\# MetaMask Desktop | メタマスク デスクトップアプリ



\[English](README.md) | \[简体中文](README.zh-CN.md)



\*\*MetaMask Desktop\*\* は、Windows、macOS、Linux ユーザー向けに開発された、暗号資産ウォレット管理および Web3 アプリケーション対応のクロスプラットフォーム・デスクトップアプリです \[MetaMask-AI/metamask-desktop](https://github.com/MetaMask-AI/metamask-desktop)。従来のブラウザ拡張機能（拡張版メタマスク）に依存しないスタンドアロン環境を提供し、高い安定性、パフォーマンス、そしてシステム層とのシームレスな連携によって、DeFi や NFT などの分散型エコシステムへの快適なアクセスを実現します。



\## 主な機能



\- \*\*ブラウザ拡張機能が不要\*\*：重いブラウザのタブや起動の遅さから解放され、単体で動作します。

\- \*\*ローカル暗号化ストレージ\*\*：秘密鍵はデバイス内に暗号化されて安全に保管され、外部に送信されることはありません。

\- \*\*複数アカウント＆カスタム RPC 対応\*\*：マルチアカウント管理、シードフレーズのインポート/エクスポート、Ethereum、Polygon、BSC などのカスタム RPC ネットワークの切り替えに対応。

\- \*\*ハードウェアウォレット対応\*\*：主要なハードウェアウォレットと連携し、安全なコールドストレージ運用が可能。

\- \*\*Web3 プロバイダー内蔵\*\*：DApps（分散型アプリ）とシームレスに接続し、ERC-20 トークンや NFT（ERC-721）の管理・取引が可能。



\## インストール方法



\### Windows

1\. \[Releases ページ](https://github.com/MetaMask-AI/metamask-desktop/releases) から最新の `.exe` インストーラーをダウンロードします。

2\. インストーラーを実行し、画面の指示に従ってセットアップを完了します。



\### macOS

1\. \[Releases ページ](https://github.com/MetaMask-AI/metamask-desktop/releases) から最新の `.dmg` パッケージをダウンロードします。

2\. ファイルを開き、アプリケーションを \*\*Applications\*\*（アプリケーション）フォルダにドラッグ＆ドロップします。



\### Linux

1\. \[Releases ページ](https://github.com/MetaMask-AI/metamask-desktop/releases) から `.AppImage` ファイルをダウンロードします。

2\. ターミナルを開き、以下のコマンドを実行します：

&#x20;  ```bash

&#x20;  chmod +x MetaMask-Desktop-1.6.0.AppImage

&#x20;  ./MetaMask-Desktop-1.6.0.AppImage

&#x20;  ```
